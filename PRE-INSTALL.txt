============= Pre-Install =============

Suggested steps from the Arch ISO live environment before running install.sh.

0) Verify EFI:

ls /sys/firmware/efi/efivars

The directory must exist and be non-empty before proceeding.

1) Internet. Ethernet is usually automatic. For Wi-Fi:

iwctl station wlan0 connect "SSID"
ping archlinux.org

2) Partition the disk. Use lsblk to identify your disk. Use fdisk or gdisk to partition.

Suggested layout:

  /dev/nvme0n1p1   512M   EFI System
  /dev/nvme0n1p2   rest   Linux filesystem

3) Format:

mkfs.fat -F32 /dev/nvme0n1p1
mkfs.ext4 /dev/nvme0n1p2

4) Mount:

mount /dev/nvme0n1p2 /mnt
mkdir -p /mnt/boot/efi
mount /dev/nvme0n1p1 /mnt/boot/efi

5) Pacstrap:

pacstrap /mnt base base-devel linux linux-firmware linux-headers intel-ucode \
    grub efibootmgr git networkmanager

6) Fstab:

genfstab -U /mnt >> /mnt/etc/fstab

Verify the output looks correct before continuing.

7) Chroot:

arch-chroot /mnt

8) Inside chroot:

Timezone:
  ln -sf /usr/share/zoneinfo/America/Vancouver /etc/localtime
  hwclock --systohc

Locale - edit /etc/locale.gen, uncomment your locale (e.g. en_CA.UTF-8), then:
  locale-gen
  echo "LANG=en_CA.UTF-8" > /etc/locale.conf

Hostname:
  echo "majatux" > /etc/hostname

Hosts - edit /etc/hosts:
  127.0.0.1   localhost
  ::1         localhost
  127.0.1.1   majatux.localdomain majatux

Root password:
  passwd

Bootloader:
  grub-install --target=x86_64-efi --efi-directory=/boot/efi --bootloader-id=GRUB
  grub-mkconfig -o /boot/grub/grub.cfg

9) Ready. Copy this directory into the chroot (e.g. under /root/), then run:

bash install.sh


============= Appendix: Developer Notes =============

BEWARE: The following will wipe $DISK entirely. Verify every variable before
running anything. Run each block separately.

Part 1 - set variables first:

  DISK="/dev/vda"
  HOSTNAME="tuxbox"
  LOCALE="en_CA.UTF-8"
  TIMEZONE="America/Vancouver"
  [[ "$DISK" =~ nvme ]] && SEP="p" || SEP=""

Part 2 - pre-chroot:

  sgdisk --zap-all "$DISK"
  sgdisk -n 1:0:+512M -t 1:ef00 -c 1:"EFI"   "$DISK"
  sgdisk -n 2:0:0     -t 2:8300 -c 2:"Linux" "$DISK"
  partprobe "$DISK"

  mkfs.fat -F32 "${DISK}${SEP}1"
  mkfs.ext4 "${DISK}${SEP}2"
  mount "${DISK}${SEP}2" /mnt
  mkdir -p /mnt/boot/efi
  mount "${DISK}${SEP}1" /mnt/boot/efi
  pacstrap /mnt base base-devel linux linux-firmware linux-headers intel-ucode grub efibootmgr git networkmanager neovim
  genfstab -U /mnt >> /mnt/etc/fstab

Part 3 - configure system:

  arch-chroot /mnt /bin/bash -c "
    ln -sf /usr/share/zoneinfo/$TIMEZONE /etc/localtime && hwclock --systohc
    sed -i 's/^#$LOCALE/$LOCALE/' /etc/locale.gen && locale-gen
    echo LANG=$LOCALE > /etc/locale.conf
    echo $HOSTNAME > /etc/hostname
    printf '127.0.0.1 localhost\n::1 localhost\n127.0.1.1 $HOSTNAME.localdomain $HOSTNAME\n' >> /etc/hosts
    grub-install --target=x86_64-efi --efi-directory=/boot/efi --bootloader-id=GRUB
    grub-mkconfig -o /boot/grub/grub.cfg
  "
  arch-chroot /mnt passwd
